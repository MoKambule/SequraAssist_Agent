# Sequra Assist

### AI-Powered Security & Quality Risk Management

Sequra Assist is an **AI-powered security risk management assistant** designed to help startups and small businesses make better security testing decisions.

Many small teams have access to security tools, but may not have the expertise or resources to determine **what to test first, which risks matter most, and what action to take**.

Sequra Assist addresses this gap by using business and application context to:

* Understand the organisation's security needs
* Identify and prioritise security risks
* Recommend relevant security tests
* Work with existing security testing tools
* Analyse security findings
* Prioritise risks based on business impact
* Provide clear recommendations for next steps

### Core Concept

**Business Context → Risk Assessment → Test Selection → Security Testing → Result Analysis → Risk Prioritisation → Recommendations**

Sequra Assist is **not designed to replace existing security tools**. Instead, it acts as an intelligent layer that helps determine **which tests to run, why they matter, and what the business should focus on first**.

### Initial Technology

* **Python** — agent and application logic
* **Streamlit** — user interface/dashboard
* **OWASP ZAP** — web/API security testing
* **Semgrep** — source-code security analysis
* **Trivy** — dependency and vulnerability scanning

### Project Goal

The initial goal is to build a working prototype that demonstrates how an AI assistant can take business context, recommend appropriate security testing, analyse the results, and turn technical security findings into **clear, prioritised business actions**.

> **Sequra Assist — Know what to test. Know what matters.**
